Concepto y Tipos de Base de Datos

Bases de datos Relacionales (RDBMS)

Las bases de datos relacionales organizan la información en tablas, que están formadas por filas y columnas. Cada fila representa un registro y cada columna contiene un tipo específico de dato, como un nombre, una edad o una dirección. Algunos ejemplos comunes de sistemas de gestión de bases de datos relacionales son MySQL y PostgreSQL, que permiten almacenar, consultar y administrar datos de forma estructurada.

Bases de datos No Relacionales (NoSQL)

Las bases de datos NoSQL permiten almacenar información no estructurada o semiestructurada, sin necesidad de utilizar tablas tradicionales. Organizan los datos en diferentes formatos, como documentos, pares clave-valor y grafos, lo que ofrece flexibilidad y facilita el manejo de grandes volúmenes de información. Un ejemplo común es MongoDB, que almacena los datos en documentos, generalmente en formato similar a JSON.

    Tablas (Entidades): Estructuras donde se organizan los datos.

    Campos (Atributos): Columnas que definen la tipologia de informacion.

    Regustros (Tuplas): Filas que contienen cada instancia concreta de datos.

    Claves Primarias (Primary key): Identificadores unicos para cada registro.

Relacion 1:1

Cada registro de una tabla se relaciona con un único registro de otra. Ejemplo: una persona tiene un único DNI.

Relacion 1:N

Un registro de una tabla puede relacionarse con varios registros de otra. Ejemplo: un cliente puede realizar varios pedidos.

Relacion N:M

Varios registros de una tabla pueden relacionarse con varios de otra. Ejemplo: varios estudiantes pueden cursar distintas asignaturas. Se utiliza una tabla intermedia para establecer la relación.

Clave Foranea (Foreign Key)

Una clave foránea es un campo que permite vincular dos tablas, haciendo referencia a la clave primaria de otra tabla. Su función es mantener la integridad de los datos y garantizar que las relaciones entre tablas sean coherentes. Ejemplo: el identificador de un cliente en la tabla de pedidos permite relacionar cada pedido con su cliente correspondiente.

Glosario de Terminos

    SQL (Structured Query Language): Lenguaje utilizado para crear, consultar y modificar datos en bases de datos relacionales.

    SGBD (Sistema de Gestión de Bases de Datos): Software que permite crear, administrar y gestionar bases de datos, como MySQL o PostgreSQL

    Normalización: Proceso de organizar los datos en tablas para reducir duplicidades y evitar errores o inconsistencias.
